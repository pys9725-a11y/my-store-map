# my-store-map

대리점 위치를 지도에 시각화하는 Streamlit 연습 프로젝트입니다.

## ⚠️ 개인정보 관련 주의사항

`app.py`에는 구글 시트 ID가 코드에 하드코딩되어 있습니다. 이 시트가 "링크가 있는 모든 사용자"에게
공개되어 있고, 이 저장소(repository)가 public이라면 **대표자명, 전화번호, 주소 등 개인정보가
누구에게나 노출**될 수 있습니다. 배포 전 아래 중 하나를 확인해주세요.

- 저장소를 private으로 유지하기, 그리고/또는
- 구글 시트 공유 설정을 제한하고, 서비스 계정 인증 등으로 서버 사이드에서만 데이터를 읽도록 변경하기
